## About Overall

Overall is an independent cybersecurity initiative founded in **Latin America**, focused on systems research, vulnerability analysis, and offensive tool development.

We aim to contribute to the cybersecurity community by sharing technical knowledge, publishing practical guides, and developing tools that support learning and security research. Our work emphasizes understanding how systems operate, investigating security weaknesses responsibly, and turning research into useful technical resources.

## Focus Areas

- **Systems Research** — Exploring operating systems, internals, and low-level behavior.
- **Vulnerability Research** — Studying security weaknesses and documenting findings responsibly.
- **Security Tool Development** — Building tools for authorized testing, analysis, and research.
- **Technical Education** — Sharing practical guides, write-ups, and learning resources.

## Responsible Research

Practice only in your own lab, on platforms designed for security training such as Hack The Box, or on systems for which you have explicit authorization. If you discover a vulnerability in real-world software, follow the applicable disclosure process: report it privately to the responsible party and allow time for a fix before sharing details publicly.

## Principles

- **Responsible research:** Respect authorization, laws, and program scope.
- **Knowledge sharing:** Make technical learning more accessible through clear documentation.
- **Continuous learning:** Build strong foundations, test ideas, and learn from results.
- **Community:** Encourage collaboration, curiosity, and professional growth.
